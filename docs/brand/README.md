# LEDGER logo: "The Corner Pin"

The L is a wall corner from a floor plan (two thick walls meeting); the red dot is the damage pin from the 3D view, sitting in the corner. A plan, a spot, a proof.

- `mark.svg`: the mark on light backgrounds (ink `#0e0e0c`, red `#ff4f1f`, Alex's tokens). In the app it is drawn inline in `apps/web/components/Header.tsx`.
- `icon.svg`: app / favicon version (white L and red dot on ink, rounded square). Same file as `apps/web/app/icon.svg`.
- `board.png`: preview of the lockup on light and dark, top-bar size and the icon at 128/64/32/16 px.
- Name: LEDGER. Tagline: "No proof, no charge."
